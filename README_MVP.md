# 课文小老师 MVP 试用说明

## 打开方式

真实 OCR 版本需要先启动本地服务。

1. 复制 `.env.example`，改名为 `.env`。
2. 在 `.env` 里填写你的 `OPENAI_API_KEY`。
3. 双击 `START_LOCAL.bat`。
4. 浏览器打开 `http://localhost:8787`。

不要再直接用 `file://` 打开 `index.html`，否则 OCR 服务不会一起工作。

## 当前已实现

- 创建或进入家庭空间。
- 添加和选择小朋友姓名。
- 创建或选择当前课文。
- 单独拍照/上传课文或配套习题素材。
- 支持多张图片归为同一篇课文或同一组习题。
- 课文图片、配套习题、生成练习、作答反馈都基于当前课文串联。
- 多张图片会并列显示为缩略图，并可拖拽排序、上移、下移或删除。
- 课文和配套习题各自有独立草稿，切换类型不会混用上一类 OCR 文本。
- 上传图片后需要点击“一键 OCR”，识别文本才会出现在下方校对区。
- 在生成练习时选择已保存的课文素材和习题素材。
- 使用《大禹治水》示例课文和配套习题。
- 生成填空默写，支持轻度、中度、重度。
- 填空默写支持显示或隐藏拼音。
- 生成做题练习，暂不分轻度、中度、重度，只根据配套习题生成同类型题。
- 一键复制学生版内容。
- 一键下载 Word 文档，包含学生版和答案版。
- 保存练习批次到留档。
- 记录作答反馈。
- 按当前小朋友查看练习批次和反馈记录。

## 当前还是模拟的部分

- 家庭空间目前保存在当前浏览器本地，后续产品打磨稳定后再接云端数据库。
- OCR 使用本地服务调用百度智能云 OCR，需要你自己的百度 OCR API Key 和 Secret Key。
- 拍作答后的自动批改尚未接入，当前先支持手动记录反馈。
- 图片文件本身暂时不上传云端；当前先用于本地预览和流程打磨。

## 推荐试用流程

1. 创建家庭空间。
2. 添加小朋友姓名。
3. 创建或选择当前课文，例如“大禹治水”。
4. 进入“拍课文/习题”，上传课文图片，可一次选择多张。
5. 保存为当前课文下的课文素材。
6. 如果课文跨页，确认缩略图显示的页序，必要时拖拽、上移、下移或删除。
7. 再上传配套习题图片，可一次选择多张。
8. 如果习题跨页，确认缩略图显示的页序，必要时拖拽、上移、下移或删除。
9. 保存为当前课文下的一组习题素材。
10. 进入“生成练习”，系统只展示当前课文下的课文素材和习题素材。
11. 选择填空默写或做题练习。
12. 选择难度和拼音提示。
13. 点击生成预览。
14. 下载 Word 或复制学生版。
15. 点击保存留档。
16. 进入“拍作答”，选择当前课文下的练习，记录孩子做题结果。
17. 到“留档”查看当前课文下的练习批次和反馈。
